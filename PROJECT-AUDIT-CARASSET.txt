1. KONDISI PROYEK SAAT INI
----------------------------------------------------------------------
Proyek adalah instalasi Laravel skeleton BARU/DEFAULT (laravel/laravel)
yang belum diubah sama sekali. Tidak ada halaman, route, controller,
atau aset custom yang sudah dibuat. Ini adalah kondisi "clean slate"
yang aman untuk memulai pembangunan front-end CarAsset.

Bukti:
- routes/web.php hanya berisi satu route default "/" yang mengembalikan
  view "welcome".
- resources/views/ hanya berisi welcome.blade.php (default Laravel,
  223 baris, memakai markup & style Tailwind bawaan Laravel).
- app/Http/Controllers/ hanya berisi Controller.php dasar (kosong,
  belum ada controller custom).
- app/Models/ hanya berisi User.php bawaan.
- public/ hanya berisi file bawaan: .htaccess, favicon.ico, index.php,
  robots.txt. Tidak ada folder public/assets, tidak ada public/build.
- node_modules belum di-install (belum pernah dijalankan npm install).
- vendor/ sudah ter-install (composer install sudah pernah dijalankan).
- database menggunakan SQLite (DB_CONNECTION=sqlite) — bawaan default,
  belum ada migrasi/tabel custom yang relevan dengan CarAsset.

5. POTENSI KONFLIK ATAU RISIKO
----------------------------------------------------------------------
a. Tailwind CSS terpasang di composer/package.json & diimpor di
   resources/css/app.css. Ini BERTENTANGAN dengan ketentuan proyek
   ("CSS biasa tanpa Tailwind"). MITIGASI: front-end CarAsset TIDAK
   akan memakai resources/css/app.css maupun @vite directive sama
   sekali; seluruh CSS CarAsset akan berada di public/assets/css dan
   dimuat lewat tag <link> biasa dengan helper asset(). File Tailwind
   bawaan dibiarkan tidak terpakai (tidak perlu dihapus di tahap ini,
   sesuai batasan "jangan ubah file proyek yang sudah ada").
b. Route "/" saat ini mengarah ke view('welcome') bawaan. Pada
   PROMPT 01 route ini PERLU diarahkan ke halaman Home CarAsset —
   ini akan jadi satu-satunya perubahan pada routes/web.php, dan
   BUKAN "route yang sama dengan konflik", karena tidak ada route lain
   yang bentrok. Tidak ditemukan route ganda/konflik penamaan.
c. Belum ada layout Blade (layouts/app.blade.php) sama sekali —
   perlu dibuat baru, tidak ada file lama yang akan tertimpa.
d. Belum ada folder public/assets — aman dibuat baru tanpa risiko
   menimpa apa pun.
e. node_modules belum ter-install — jika suatu saat "npm run build"
   dijalankan tanpa sengaja, Tailwind akan ikut ter-compile ke
   public/build. Karena proyek CarAsset tidak memakai Vite untuk
   front-end statisnya, sebaiknya proses build Vite/Tailwind ini
   TIDAK dijalankan selama pengerjaan CarAsset agar tidak membingungkan
   (tidak perlu dihapus, cukup tidak disentuh/dijalankan).
f. Tidak ditemukan package backend lain yang berpotensi konflik
   (tidak ada Livewire, Inertia, Filament, Breeze, Jetstream, dsb).
g. Tidak ditemukan CSS/JS global lama, tidak ada folder
   public/css atau public/js lama yang bisa bentrok nama dengan
   public/assets.
h. Kesimpulan: TIDAK ADA konflik struktural nyata. Risiko yang ada
   murni berasal dari starter-kit Tailwind/Vite bawaan yang cukup
   diabaikan (bukan dihapus) selama tahap front-end statis CarAsset.

8. REKOMENDASI ROUTE DAN CONTROLLER
----------------------------------------------------------------------
Kondisi: hanya 5 halaman statis, tanpa form backend, tanpa database,
tanpa autentikasi. Tidak ada logika bisnis di server-side selain
merender view.

REKOMENDASI: gunakan SATU controller sederhana, mis.
  app/Http/Controllers/PageController.php
dengan 5 method (home, business, partnership, simulation, aboutContact)
yang masing-masing hanya `return view(...)`.

Alasan memilih controller dibanding closure route:
- routes/web.php tetap ringkas dan mudah dibaca meski nanti perlu
  ditambah data statis sederhana (mis. array FAQ, array paket) tanpa
  mengotori file route.
- Lebih mudah dites lewat PHPUnit bila diperlukan nanti.
- Tetap sangat ringan (tidak melanggar batasan "tidak membuat backend
  form/database/login/dashboard") karena controller hanya mengembalikan
  view, tidak ada model/migration/query.

Closure route juga valid dan lebih minimal, namun controller tunggal
lebih rapi untuk 5 halaman + kemungkinan section dinamis di masa depan.
Keputusan akhir tetap menunggu instruksi PROMPT 01 sebelum dieksekusi.

9. REKOMENDASI PEMUATAN CSS, JAVASCRIPT, DAN FONT
----------------------------------------------------------------------
- TIDAK memakai @vite() dan TIDAK memakai resources/css/app.css /
  resources/js/app.js bawaan. Direktif Vite pada welcome.blade.php
  tidak akan digunakan pada layout CarAsset yang baru.
- Seluruh CSS/JS dimuat lewat tag <link rel="stylesheet"> dan
  <script src="..."> biasa di dalam layouts/app.blade.php, dengan
  path memakai helper asset(), contoh:
    asset('assets/css/base/reset.css')
    asset('assets/js/global/main.js')
- Font League Spartan, Poppins, dan DM Sans dimuat via Google Fonts
  <link> (atau font lokal bila diminta klien nanti) di
  partials/seo-meta.blade.php atau langsung di <head> layout, BUKAN
  lewat @fonts/bunny plugin bawaan Vite.
- Ikon Lucide dipanggil terpusat satu kali di layout (CDN script atau
  local SVG sesuai keputusan nanti), tidak di-load ulang per halaman.
- Vite TIDAK diperlukan untuk tahap awal sesuai ketentuan proyek;
  npm install/npm run dev/build tidak perlu dijalankan selama proyek
  CarAsset dikerjakan dengan pendekatan ini.
